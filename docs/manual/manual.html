1. 이 프로그램은 무엇인가요

영어 문장을 입력하면 내 맥 안에서 이미지를 만들어 주는 프로그램입니다. 인터넷 서비스에 그림을 올리지 않고, 사용료도 없습니다. 미드저니처럼 한 번에 4장이 나오고, 마음에 드는 그림의 구도를 유지한 채 문장만 바꿔 다시 만들 수 있습니다.

만든 모든 그림에는 사용한 문장, 출발점 번호(시드), 걸린 시간, 품질 검사 결과가 함께 기록됩니다.

2. 준비물

항목내용
맥Apple 실리콘 맥 (M1 · M2 · M3 · M4). macOS 11 이상. 인텔 맥은 확인하지 않았고, 되더라도 매우 느립니다
저장 공간10GB 이상 여유 (프로그램 1–2GB + 그림 모델 약 2.6GB + 결과물)
인터넷처음 설치할 때만 필요합니다. 설치 후에는 인터넷 없이도 그림을 만들 수 있습니다.
맥 로그인 비밀번호Python을 설치할 때 한 번 입력합니다.
시간설치 10–30분 (인터넷 속도에 따라). 그림은 장당 몇 초.
Python, Homebrew, 개발자 도구는 미리 설치할 필요가 없습니다. 설치 프로그램이 필요한 것을 공식 사이트에서 받아 설치하고, Python 설치 파일은 공식 서명(Python Software Foundation)을 확인한 뒤에만 설치합니다.

3. 설치하기 (처음 한 번)

  1. 터미널 열기 키보드에서 ⌘ Command + Space를 누르면 검색창(Spotlight)이 뜹니다. 터미널이라고 입력하고 Enter. 검은(또는 흰) 글자 창이 열리면 됩니다.
  2. 아래 한 줄을 그대로 복사해서 터미널에 붙여 넣고 Enter
    curl -fsSL https://raw.githubusercontent.com/cogito5170/diffusion_model/HEAD/install_mac.sh | bash
    붙여 넣기는 ⌘ Command + V. 반드시 한 줄로 들어가야 합니다. 두 줄로 나뉘어 들어갔다면 지우고 다시 붙여 넣으세요.
  3. 진행 상황 지켜보기 화면에 단계가 차례로 나옵니다.
    단계하는 일
    [1/5]Python 확인. 없으면 python.org에서 받아 설치합니다 → 비밀번호 입력 (아래 4번)
    [2/5]프로그램 받기 → 홈 폴더의 diffusion_model
    [3/5]필요한 부품 설치 (가장 오래 걸립니다)
    [4/5]그림 모델 받기 (약 2.6GB)
    [5/5]바탕화면에 아이콘 두 개 만들기
  4. Password:가 나오면 맥에 로그인할 때 쓰는 비밀번호를 입력하고 Enter. 입력하는 동안 화면에 아무것도 보이지 않는 것이 정상입니다.
  5. "설치 완료!"가 나오면 끝 바탕화면에 이미지 스튜디오와 이미지 만들기 아이콘이 생깁니다. 터미널 창은 닫아도 됩니다.
빨간 글씨가 나오며 멈추면, 안내 문구를 따른 뒤 같은 한 줄을 다시 실행하세요. 이미 끝난 단계는 건너뜁니다. 그래도 안 되면 홈 폴더의 diffusion_model_install.log 파일을 보내 주세요.

4. 이미지 스튜디오 쓰기

바탕화면의 이미지 스튜디오를 더블클릭하면 터미널 창이 하나 뜨고, 잠시 뒤 브라우저에 아래 화면이 열립니다. (터미널 창은 프로그램이 돌아가는 곳이니 쓰는 동안 닫지 마세요.)

  1. 맨 위 칸에 영어 문장을 쓰고 Enter (또는 만들기 버튼) 첫 장은 모델을 불러오느라 10초 정도, 그다음부터는 장당 2–4초.
  2. 옵션 고르기비율 · 장수 · 시드 · 자르기를 문장 아래에서 고를 수 있습니다. 문장 끝에 옵션을 직접 써도 됩니다 (아래 표).
  3. 그림 위에 마우스를 올리면 버튼이 나옵니다. 이 시드로: 구도는 그대로 두고 문장만 바꿔 보기 · 크게: 크게 보기 · 저장: 파일로 받기. 카드 오른쪽 위 다시 뽑기는 같은 문장으로 새로 4장.
  4. 끝내기터미널 창을 닫으면 됩니다. 만든 그림은 지워지지 않습니다.
옵션뜻예
--ar가로:세로 비율 (최대 3:1)--ar 16:9
--n몇 장 (1–4)--n 2
--seed출발점 번호. 같은 문장 + 같은 시드 = 같은 그림--seed 1234
--crop지면 칸 크기로 가운데를 잘라 따로 저장--crop 574x172

5. 좋은 문장(프롬프트) 쓰는 법

이 그림 모델은 작고 빠른 대신 앞쪽 약 50–60단어까지만 읽습니다. 다음 다섯 가지만 지키면 결과가 크게 좋아집니다.

  1. 영어로 씁니다. 한국어는 거의 이해하지 못합니다.
  2. 가장 중요한 것을 맨 앞에. 주인공 → 재질 → 빛 → 색 → 분위기 순서로.
  3. "~하지 마"는 쓰지 않습니다. no people이라고 쓰면 오히려 사람이 나올 수 있습니다. 원하지 않는 것은 아예 언급하지 마세요.
  4. 하나만 바꿔 비교합니다. 마음에 드는 그림의 이 시드로를 누르고 단어 하나만 바꾸면, 그 단어가 무엇을 바꾸는지 정확히 보입니다.
  5. 4장은 같은 문장의 변주입니다출발점(시드)만 다릅니다. 마음에 드는 것을 고르세요.

예시

half-carved plain chair emerging from a raw matte white foam block, dark gallery floor, low raking light from the left --ar 16:9
translucent grey sunglasses at the edge of a long still puddle on wet concrete, one thin red light reflected in the water, night, black and olive tones --ar 16:9 --crop 574x172
one low bent brushed stainless steel arch sculpture alone on concrete under a luminous ceiling, soft even light, white room --ar 3:2
긴 띠 모양 지면(예: 574×172)은 --ar 16:9로 만들고 --crop 574x172로 가운데를 잘라 쓰세요. 중요한 것이 화면 가운데 가로 띠에 오도록 문장을 쓰면 좋습니다.

6. 결과물 · 업데이트 · 삭제

결과물은 어디에?

Finder → 홈 폴더 → diffusion_model → runs. 작업마다 run_studio-날짜-시간 폴더가 생기고, 그 안의 images에 그림, job.json에 문장과 시드가 저장됩니다. 스튜디오의 저장 버튼으로 바로 받아도 됩니다.

업데이트

설치할 때와 같은 한 줄을 다시 실행하면 최신 버전으로 바뀝니다. 만든 그림(runs)은 그대로 남습니다.

메뉴 프로그램 (이미지 만들기)

바탕화면의 이미지 만들기는 같은 기능을 질문-대답 방식으로 쓰는 메뉴입니다. 미리 설계해 둔 작품(스틸 조각 · 흰 폼 의자 · Memory of Space)도 여기서 번호만 골라 만들 수 있습니다.

완전히 지우려면

지울 것위치
프로그램과 만든 그림홈 폴더의 diffusion_model 폴더
그림 모델 (약 2.6GB)홈 폴더의 숨김 폴더 .cache/huggingface (Finder에서 ⌘+Shift+.로 표시)
바탕화면 아이콘이미지 스튜디오 · 이미지 만들기
Python (다른 곳에 안 쓴다면)응용 프로그램 폴더의 Python 3.12

7. 문제가 생겼을 때

증상해결
command not found문장(프롬프트)을 터미널에 직접 붙여 넣은 경우입니다. 문장은 스튜디오 화면이나 메뉴 안에 입력하세요.
zsh: parse error설명 글까지 같이 붙여 넣은 경우입니다. 명령 한 줄만 붙여 넣으세요.
설치 명령이 두 줄로 들어감지우고, 한 줄로 다시 붙여 넣으세요.
"확인되지 않은 개발자" 경고아이콘을 우클릭 → 열기 → 열기. (시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"가 나올 수도 있습니다)
브라우저가 안 열림브라우저 주소창에 http://127.0.0.1:7860 입력
그림이 까맣게 나옴터미널에서 한 줄 실행:
cd ~/diffusion_model && ATELIER_DTYPE=float32 .venv/bin/python studio.py
engine unavailable ... not in the local Hugging Face cache그림 모델이 아직 없습니다. 설치 한 줄을 다시 실행하세요.
Address already in use스튜디오가 이미 켜져 있습니다. 열려 있는 터미널 창을 모두 닫고 다시 더블클릭하세요.
그 밖의 오류터미널의 빨간 메시지와 diffusion_model_install.log를 보내 주세요.

8. 알아 둘 것

화질

이 모델(sd-turbo)은 속도를 위해 작게 만든 모델입니다. 원래 512px 크기로 학습되었고, 결과는 768×432 정도입니다. 화면에서 보기에는 괜찮지만 크게 확대하거나 인쇄하면 흐릿합니다. 고화질이 필요하면 더 큰 모델이나 업스케일이 필요합니다 (별도 작업).

라이선스 · 안전

이 모델에는 유해 이미지 필터가 없습니다. 개인 작업용으로는 괜찮지만, 걸러지지 않은 결과를 공개 서비스에 그대로 올리지 마세요. 상업적으로 쓰기 전에는 모델(Stability AI) 라이선스 조건을 확인하세요.
